# Radar · Dictamen independiente de fuentes de ensayo

7/11/2026, Europe/Madrid. Se cotejaron los tres hashes presentados y se revisó la fábrica frente al contrato CORE aceptado. La repetición de `tsx --test tests/commitment-demo.test.ts` pasó 6/6. Los casos usan el modelo y la API con Store y autorización locales.

El conjunto distingue instalación bloqueada, entrega sana con prueba, soporte indisponible, pedidos parciales, vínculo ambiguo y datos antiguos. Las dos cuentas con el mismo ID de pedido conservan identidades distintas. El vínculo candidato no recibe observación por coincidencia de ID o título. La consulta no escribe y las fuentes se identifican como ficticias.

Dictamen favorable para la fábrica. Al montar la candidata, guardar una sola fecha de creación del dataset y reutilizarla al reiniciar. Generar la fábrica con Date.now en cada arranque cambia su huella y abre otro ámbito de decisiones, como establece CORE. El ejemplo del informe sirve para un ensayo aislado. El recorrido persistente empleará un instante guardado en la propia instalación de ensayo. El reloj de evaluación se elegirá explícitamente en esa candidata y aparecerá como alcance de demostración si queda fijado.

El componente de usuario, el registro en main, los controles del simulador y las descargas conservan sus unidades sucesoras. Esta aceptación acredita datos de ensayo y su proyección, con cero lecturas de proveedores reales.
